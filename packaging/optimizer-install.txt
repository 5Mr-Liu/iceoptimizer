ICE RLCraft Optimizer installation
==================================

Copy the ONE ice-rlcraft-optimizer-<version>.jar from this ZIP into mods.
The same JAR contains the ordinary mod, startup transformer and early ABI.
Stop the game/server and remove older optimizer Main/Core JARs before upgrading.
Install the exact same optimizer version on client and dedicated server.
Profiler remains optional; ice-rlcraft-profiler-<version>.jar includes its probes.

安装方法：把 ZIP 内唯一的 ice-rlcraft-optimizer-<版本>.jar 放入 mods。
这个文件已包含普通模组入口、启动转换器和早期接口。
升级前关闭游戏/服务端，移除旧版 optimizer Main/Core 两个 JAR。
客户端和独立服务端必须安装完全相同的优化器版本。
Profiler 是单独发布的可选工具，单个 ice-rlcraft-profiler-<版本>.jar 已含探针。
