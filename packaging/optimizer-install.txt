ICE 1.20.3 地形重建卡顿修复与精简优化
日期：2026-11-07

适用：Minecraft 1.12.2 / Forge 14.23.5.2860 / Java 8 / RLCraft Dregora。
1.20.3 是 ICE 模组版本，不是 Minecraft 游戏版本。

安装
----
1. 完全退出客户端和服务端。
2. 把 mods 目录里所有旧 ICE Optimizer JAR 移出并保留备份，
   包括 local-test/slim 候选以及旧 Main/Core 拆分包。
3. 只放入 ice-rlcraft-optimizer-1.20.3.jar，再启动游戏。
   不要把 ZIP 放入 mods，不要同时安装多个 ICE Optimizer 版本。
4. 联机客户端和服务端都升级到 1.20.3。
   可以保留 config/ice-optimizer.cfg，无需删除配置或存档。
5. 启动日志标识应为 release-1.20.3-20261107。

本次修改
--------
发布用户已实机确认效果的精简候选，运行逻辑保持一致。
GL43 网格替换恢复旧显存区间复用，减少同尺寸区块重建触发的扩容和复制。
撤下新增 Capability NBT 结果比较、Trinkets 标量缓存和差量同步接入。
旧 Trinkets 相关配置即使保存 true 也不会重新启用这两项功能。
保留原装备 NBT、已知 Capability 状态、QualityTools、Lycanites、
Recurrent 清理优化，以及空 VBO、世界切换、物品动画和资源代次修复。
相对远程 1.20.2，纳入 OpenGL 2.1、多重纹理、索引和命令上传优化。

启用与兼容
----------
优化默认开启。已有配置中显式关闭的保留项目仍保持关闭。
F6 暂停/恢复可切换的优化；切换会重建网格，等加载稳定后再比较。
物品动画等启动补丁不随 F6 暂停。
支持 OpenGL 4.3 时使用 GL43，否则自动使用 OpenGL 2.1 兼容后端。
低于 2.1 会明确报错；旧 nativeTerrainOpenGl21 配置不再参与选择。
保留整合包已有 RenderLib。使用 ICE 自有地形时移出 Nothirium，
关闭 OptiFine Smart Animations、Fast Render 和 Render Regions。
安装 Nothirium 时遵循现有外部渲染器所有权规则。
光影包自身的硬件要求仍适用，不同显卡、驱动及 Android/gl4es 需实测。

用户已确认精简候选效果；本次打包没有新增游戏内 FPS 基准测量。
其他设备的 TerrainVisibilityAccessor 注入失败仍需完整启动日志定位，
不宣称本版已修复。完整构建与自动验证结果见 Release 的 BUILD-INFO.txt。

本包只含优化器，不含分析器、测试夹具、agent 或第三方模组。
回退时退出客户端和服务端，两端一起移出 1.20.3，恢复旧 JAR 和配置备份。
出现异常时保留 latest.log、崩溃报告及截图，并注明 F6 状态和光影包。
