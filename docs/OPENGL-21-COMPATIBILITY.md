# OpenGL 自动选择与 2.1 / gl4es 固定页实现

保留原有 OpenGL 4.3 后端，增加 OpenGL 2.1 兼容后端。两者共用区块构建、网格缓存、可见性、面剔除、透明排序、区块动画和上传任务调度。空 VBO 清理与双截棍贴图动画修复继续保留。

## 启动选择

在实际图形上下文建立、OpenGlHelper 初始化完成后，地形渲染器构造前选择一次并缓存：

| 实际上下文能力 | 后端 |
| --- | --- |
| OpenGL 4.3 或更高 | 原有 4.3 后端 |
| OpenGL 2.1 或更高但不足 4.3 | 2.1 兼容后端 |
| 不支持 OpenGL 2.1 | 明确报告最低要求不满足 |

保持 `B:nativeTerrainRenderer=true` 即可；无须新增兼容开关。旧配置中的 `nativeTerrainOpenGl21` 即使残留也不再读取，不影响选择。日志中的 `ICE_NATIVE_TERRAIN selected OpenGL ... backend; context=...` 表示启动结果。后续不逐帧检测能力，不尝试扩展组合，不在运行中切换后端。F6、世界切换和资源重载可以重建网格，但不会改变已选择的后端。

独立 Nothirium 的现有外部渲染器所有权规则仍然优先，不会同时接管。

## 2.1 缓冲页

每页共享 131,064 个顶点及配对的 16 位索引槽；普通 28 字节顶点格式每页总容量 3,931,920 字节（约 3.75 MiB），光影 56 字节格式 7,601,712 字节（约 7.25 MiB）。多个网格共用一页，按页内空洞最佳适配分配。页满时新增固定容量页，旧网格的页和偏移保持稳定。

不再通过 `glGetBufferSubData` 读回、复制旧缓冲或保留完整 CPU 网格副本。释放范围合并相邻空洞；最后一个网格释放后删除该页的顶点与索引缓冲，页编号可重用。大网格仍按 65,532 个顶点、完整四边形分段，可跨页；提交严格遵守原顺序，不按页重新排序透明面。

分配和几何上传发生在现有上传调度内。新网格的全部分段上传成功后才发布并释放旧网格；分配/Java 异常时回收新分段，原网格保持有效。绘制阶段只使用已完成网格，不扩容几何存储；视角变化导致的索引更新继续按原有帧准备流程执行。

固定页消除了全缓冲迁移，但驱动分配、同一缓冲上更新和 GPU 同步仍可能产生等待。页内碎片和新旧网格短暂并存也会占内存；不能把固定页等同于无卡顿或零额外内存。上游 gl4es 可能有自己的 CPU 副本，本实现的容量统计不代表驱动/系统总内存。

## VBO 接管范围

保留全局 `OpenGlHelper.useVbo()` 原方法。ICE 专用地形判断忽略保存的游戏 VBO 开关；继续检查硬件和区域渲染限制。2026-10-31 起，对 G5 多重纹理结构验证通过后由 ICE 保存并绘制材质范围，允许 AF/AA 触发的多重纹理模式。未知材质结构明确报错，不盲目放行或切换后端。

专用入口覆盖地形容器/工厂、RenderChunk 缓冲构造、ChunkRenderDispatcher 上传及地形绘制（包括 F6 保留路径）。RenderGlobal 中用于天空和星星的全局 VBO 标志保留原行为。关闭 OptiFine Smart Animations、Fast Render 和 Render Regions 的现有使用要求仍适用。

2.1 实现使用 GLSL 1.20、VBO、`glBufferSubData` 和普通 `glDrawElements`。顶点指针偏移替代 BaseVertex，逐次 uniform 更新替代实例属性；不调用 VAO、间接绘制、持久映射或高版本缓冲复制接口。光影路径保留 OptiFine G5 的 56 字节顶点和光影包程序，光影包自身的硬件要求不因此降低。

## 构建和验证

当前本地构建标识：`optifine-multitexture-20261031`；模组与联机版本仍为 1.20.2，Minecraft 为 1.12.2。本候选制品不覆盖已发布的 v1.20.2 文件。

自动检查覆盖上下文选择缓存、旧配置忽略、真实 G5 类转换组合、VBO 保护条件、空 VBO、固定页无搬迁、空洞合并、空页释放和失败清理。`tools/run-native-compatibility-probe.ps1` 使用离屏上下文检查真实 GPU 画面与状态恢复；`-Gl43` 检查原有后端，`-Churn` 检查连续上传、卸载和重建的峰值缓冲容量及耗时分位数。

离屏像素检查包含跨页交替提交、透明顺序、雾、光照、变换、超过 65,535 的顶点地址和非零索引偏移。Churn 数据是合成上传工作帧（包含探针独有的 glFinish），不是 Minecraft 的游戏帧时间或 FPS。实际结果随构建一并保存。

本机为 Windows / NVIDIA RTX 4060 Laptop / OpenGL 4.6；兼容路径的调用静态限制在 OpenGL 2.1 范围。尚未完成 Android/Mali/gl4es 实机验证或完整光影包验证，不能据此承诺手机上的 FPS 收益。应在目标设备连续移动加载区块、反复卸载重建、切换世界和 F6 时观察进程峰值内存与帧时间尖峰。
