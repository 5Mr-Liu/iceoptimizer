空隙合并实验的局部结果

1017 次绘制 / 1,674,324 顶点。共享矩阵路径含 GPU 完成等待的平均中位耗时
0.384300 -> 0.331283 ms（局部约 -13.8%）。
但 CPU 提交平均中位耗时 0.098738 -> 0.111131 ms，增加约 0.012394 ms。
减少绘制和顶点并不自动等于减少 CPU 工作；目前仍不作为生产改动保留。
下一项明确问题是新方案使更多网格进入逐面扫描，应研究预计算连续区间，
并把 CPU 提交开销降下来后再作整包比较。
