# ICE 精简实机测试候选

日期：2026-11-07。Minecraft 1.12.2，ICE 内部版本 1.20.2，启动标识 `slim-20261107`。

基于用户反馈卡顿的 `nbt-complete-20261106` 工作区做定向精简，不是完整回滚所有源码至 1.20.1。旧测试包和其构建证据仍保存在 `build/local-test-20261107/`；本轮修改前文件副本保存在 `build/slim-20261107/before/`。

## 本次改变

1. **GL43 网格替换恢复旧区间复用。** 先使旧绘制记录失效、释放旧区间，再申请并上传新网格。这样同尺寸重建可以复用刚释放的孔洞，避免仅因保留旧网格而触发整块 GPU 存储扩容和复制。新网格仍在上传完成后发布。
2. **补齐该替换顺序的失败处理。** 上传失败时保持区块待重建、清空已经退休的顶点计数，不让绘制队列继续引用释放的地址。失败继续报告，不把异常静默吞掉。GL21 固定页依然保留旧网格直到新上传完成，避免提前释放最后一个网格导致整个页被删除再创建。
3. **撤下三个实验功能的生产接入。** 删除目标目录和适配器注册中的 `forge-capability-nbt`、`trinkets-state-nbt`、`trinkets-sync-delta`，并取消 `TrinketsSyncBridge.initialize()`。不会通告差量通道，远程连接采用原 Trinkets 消息。
4. **兼容既有配置。** `trinketsStateNbt`、`trinketsSyncDelta` 字段保留用于加载旧配置，但在此候选中不启用相应模块。即使旧文件为 true 也不会重新接入；不要求删除用户配置。旧装备 NBT 比较和已知 Capability 状态比较仍启用各自原配置，不连带关闭。

实验实现及其历史语义测试仍保留在源码中，没有再接到游戏的 writer、比较器或网络发送入口。精简针对运行路径，不声称 JAR 文件大小显著减小。

## 保留范围

保留空 VBO、世界切换、物品动画和旧上传任务资源代次处理；保留 QualityTools 属性复用、Lycanites 单次装备解析、Recurrent 世界加载清理、已知 Capability 快路径、索引批量生成和命令部分上传。

本机已存在的配置显示 AA=0、AF=1；本轮没有改这些设置。OpenGL 2.1、多重纹理及其透明排序/F6 配套继续保留，避免为了删除未启用分支改变画质和兼容范围；桌面支持 4.3 时使用 GL43 路径。

此前其他设备的 `TerrainVisibilityAccessor` 注入失败仍缺对应启动日志，本次不宣称已修复该问题。用户当前没有复现这个崩溃，本候选针对新增卡顿路径做对照。

## 验证与实测边界

新增实际 renderer 上传入口的回归：GL43 风格的 65,532 顶点替换复用原区间；GL21 风格延迟释放；两条路径上传失败时分别验证退休几何不可继续绘制、未退休旧几何仍保留。测试后端使用真实区间分配器，不创建 GPU 上下文。

另验证旧配置 true 在客户端与服务端都无法启用撤下模块；最终 JAR 检查目标目录中没有三项接入，旧装备及已知 Capability 入口仍存在，且 IceMod 不再注册差量传输。原 Trinkets NetworkHandler 经生产转换器处理后保留原字节码。

最终构建结果、测试统计、SHA256 和安装 JAR 见 `build/slim-20261107/BUILD-INFO.txt`。本次不启动 Minecraft，不覆盖游戏实例；帧时间是否改善由用户实际测试确认。

## 安装与测试

退出游戏，移出旧 ICE Optimizer JAR，只放入 `ice-rlcraft-optimizer-1.20.2-slim-20261107.jar`。保留原配置，启动日志应包含 `slim-20261107`。

使用相同存档、视距、光影和路线，重点观察移动加载区块、转向与区块重建时的卡顿。先等首次加载稳定；F6 会重建网格，不把切换瞬间当作稳定性能对照。若仍卡顿，保留本次 `logs/latest.log`，并说明是在单人还是联机、站立还是移动时出现。
