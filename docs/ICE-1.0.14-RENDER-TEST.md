# ICE 1.0.14 渲染测试构建

本版本供实际游戏对比测试，未将局部绘制调用减少换算为 FPS 承诺。目标环境仍是 Minecraft 1.12.2 / Forge 14.23.5.2860 / Java 8 / RLCraft Dregora。

## 本次路径

- 地形使用 GPU 保存的平移数据提交连续批次，减少跨 region 的矩阵切换与提交；兼容路径条目在原位置断开批次，透明层保持原顺序。
- 已知单面 SOLID 矩形按方向分组，跳过确定背向摄像机的整组顶点。未知几何保留；不修改方块模型、材质或可见距离。
- 支持的 ModelRenderer / SRP / LLibrary 部件保留静态合并网格，上传每次动画的矩阵调色板；每段上限按驱动容量选择，最多 128 个部件，状态变化处先提交。至少 8 个部件才使用新路径，更小模型保持原有状态合批；这是固定选择，不在游戏中测速。模型范围内的矩阵变换在 CPU 合并，在外部状态变化或范围结束时同步回原生矩阵栈。自定义回调与不支持的路径沿用已有绘制。
- 当前视图软件遮挡直接读取上传几何形成有限的 CPU 快照；使用实际不透明面遮挡、几何边界作为被遮挡查询，覆盖 ICE 和原生地形列表。每次用当前矩阵重建深度，不依赖历史相机，也不回读 GPU 深度。透明、未知、近裁剪面及动画中的区块保留可见。
- 启用软件遮挡时不再同时运行旧历史 HZB。地形和模型的新批处理在所需 GL 操作可用时直接启用；移除额外输出试跑、上传校验读回、预热、ABBA 收益筛选与持续收益检查。

## 游戏对比

替换旧优化器为 `build/libs/ice-rlcraft-optimizer-1.0.14.jar`。Profiler 并非启用这些优化的条件。联机双方的优化器版本需一致。

游戏内按 **F6** 暂停/恢复所有可即时切换的 ICE 优化，也可在“选项 → 控制 → ICE 优化 → 暂停/恢复 ICE 优化”中重新绑定键盘或鼠标键。屏幕提示当前状态，F3 暂停时显示 `PAUSED`；不写模块配置，重启后按原配置启用。切换在客户端 Tick 边界完成，不额外进行收益检测或在线对照试跑。

切换会重建地形，短暂卡顿/区块重新出现不应算进 FPS 对照；等区块完成后，在同地点、同视角分别记录一段稳定帧率。暂停时模型绘制走原列表，保留现有模型缓存并有界记录首次编译的新模型，恢复后继续使用。延迟动画纹理先补传，旧 Worker 队列关闭，暂停前未完成的任务不能在恢复后提交旧结果。

范围：客户端与单人集成服的运行时优化一同切换；远程独立服务端及独立 Profiler 不受影响。已加载的字节码入口、注入字段、已有导航器/缓存容器和已完成的构建/解析保留；已开始的一次寻路或扫描自然结束。暂停不是“完全卸载 ICE”的基线，原有玩家头颅联网设置也保持不变。

以下独立开关默认开启，修改后重启游戏：

| 配置项 | 比较内容 |
| --- | --- |
| `terrainShaderBatching` | 地形 GPU 平移合批；需要 OpenGL 4.3 兼容上下文，不支持时使用现有绘制 |
| `terrainDirectionalCulling` | SOLID 方向面组剔除 |
| `modelPoseBatching` | 支持的实体模型 GPU 姿态合批 |
| `terrainSoftwareOcclusion` | 当前视图软件遮挡；关闭后可按原配置使用历史 HZB |

先保持 OptiFine 快速渲染、动态视野、分辨率、视距和帧率上限一致，分别比较同一地点转动视角、怪物密集场景和跑图。新增固定管线批处理与软件遮挡在无 ShaderPack 路径生效。GPU 地形路径需要 ICE 已接管的网格；原生网格仍可参与软件遮挡。

已有 F3 行增加 `GPU 批次/命令`、`Pose 批次/部件`、`Occ 已剔除网格` 的累计计数，方便确认路径确实被使用。详细原因和计数沿用现有诊断报告；没有新增逐帧日志。

## 运行时检测精简

- 显式地形路径不再为了收益判断额外扫描覆盖率和 region 数，也不再生成场景指纹；实际绘制计划一次确定网格所有权。旧覆盖率报告在未采样时标为 `not-sampled`。
- 显式模型路径不再要求计时查询资格、不再生成收益场景指纹，也不再在 HUD 状态恢复时查询模型灯光；固定管线镜像由现有初始化和帧恢复维护。
- Lycanites 外部模型入口同步移除对旧输出验证标志的等待，避免直接启用后该入口始终回退。
- 删除合批内部已经由容量和预检保证的重复判断、冗余矩阵回调与 GL 查询；软件遮挡不再要求列表必须恰好是 `ArrayList`，也不因 atlas 总 sprite 数单独停用。
- 单个软件遮挡上传失败只丢弃对应 VBO，保留其他有效缓存。纹理透明度、近裁剪、几何/资源失效、材质边界和绘制后的状态恢复仍保留。
- 快捷键复查删除模型捕获中的重复暂停/模块查询；Pending 发布沿用已有活动帧检查，外部模型入口不再为几个状态字段分配完整 GL 快照。
- 恢复时已由资源失效完成的 GL 初始化不再重复扫描，纹理补传直接复用已知绑定镜像，仅未知状态查询 GL；深度重置不再重复清理同一个 HZB 历史。
- 启动插件提示只在首次进入世界检查一次，不再每 Tick 创建完整诊断快照；BetterCaves 删除多余断路器懒缓存。非异步头颅模式切换时不再重复配置和清理缓存。

## 验证记录

### 全模块条件复查

本轮按模块注册表、实际调用入口及相互调用关系检查了客户端和服务端优化，覆盖渲染、区块构建、纹理、动态光源、寻路、刷怪、实体属性、OTG、BetterCaves、存档压缩、缓存与异步队列。

- 所有生产渲染后端统一按配置与所需能力直接启用，包括旧模型/地形模式、HUD、粒子、动画纹理及持久映射；不再用预热、ABBA、稳定负载或回归采样决定是否启用。GPU 计时能力不再是模型、HZB 和 Shader 桥的启用条件。Shader 的实际编译、状态、图像和布局有效性仍由对应程序的现有认证维护。
- 动画纹理桥删除三路重复验证、ABBA 分支、场景指纹和相关逐帧计时。HUD、粒子、FBP 桥删除重复输出验证。地形持久写入不再无条件创建测量场景。OptiFine Region 在本代际首次确认有效提交后停止重复观察。
- 旧模型模式的成功上传也立即可绘制，避免取消在线验证后仍卡在 `ENTRY_UNVALIDATED`；资源作废时仍拒绝旧网格。
- Lycanites 刷怪扫描原先只接受精确 `ArrayList`，会拒绝方块成员索引优化生成的 ICE 列表，造成两个优化同时开启时扫描复用失效。现在认可 ICE 自己的等价列表，同时保留自定义列表的原行为。
- 寻路、实体、刷怪、保存索引等十个桥使用固定模块序号，省去热路径字符串查找；保留支持 F6 的轻量运行掩码。区块压缩、排序、上传与 Forge 方块直调等已激活路径避免重复失败 CAS。
- Dynamic Trees 缓存命中不再重复验证写入端保证的数组结构；FoamFix 同次上传删除重复 GL context 查询；纹理反射入口不再每次分配参数类型数组。头颅异步解析不再逐次执行默认初始化检测，避免关闭期间重新启动工作线程。
- Konkrete 修复同尺寸内容变化被检测后仍取回旧缓存的问题。精确 `HashMap` 限制保留：access-order `LinkedHashMap` 的 `get` 会改变原查询的首次匹配顺序，不能将类型限制当成冗余直接删除。

保留条件均有明确用途：存档版本和写入顺序、异步任务所属世界与资源代际、队列和缓存预算、真实硬件能力、未知材质/几何、用户暂停，以及小批次避免固定提交成本的阈值。旧历史 HZB 仍只复用相同视图的深度，当前默认软件遮挡不受该条件限制。OreLib 只依赖 Minecraft 部分状态缓存，没有覆盖全部字段的失效通知，不能直接去掉其原有真值核对；Kirin 对冻结子树的稳定性判断避免动画每帧重编列表，与相机移动无关。

另外，`srp-pose-cache` 和 `srp-particle-collision` 当前只有注册/配置，没有单独连接运行入口，不能计作已生效优化；保留其枚举序号，避免改变已有注入 ABI。本轮没有临时补写这两个未接线功能。

统一构建通过：普通测试 1015 项，993 通过、22 跳过、0 失败；安装包独立加载另有 10 项通过，打包检查通过。生产后端工厂在缺少计时能力、持续变化负载的 700 帧测试中保持直接启用；真实硬件缺失和用户关闭仍被正确处理。Lycanites 双模块联用回归在旧条件下失败、修复后通过。隐藏 OpenGL 验证覆盖初始化、世界/资源/上下文切换和清理无预算泄漏，F6 暂停补传的像素与绑定恢复正确；旧模型立即上传与 12 组材质/光照场景均零像素差。以上均为开发验证，不在游戏中新增试跑。最终游戏 FPS 尚未实测。

### 移动场景的专项复查

“优化路径仍执行”不能证明“移动时仍有净帧率收益”。本轮离线复查发现两处动态场景缺陷：

- Primitive visibility 遍历使用旧位置/旧可见列表作为在线基线；新位置先跑原版，转头改变可见列表还可能误报不一致。删除该独立路径残留的场景指纹、预热、在线输出扫描和 ABBA 测量，按配置直接执行等价 BFS。遍历顺序、OptiFine 实体/方块实体侧列表及实际异常处理保留。
- 软件遮挡把整块包围盒的可查询性错误地当成墙面能否遮挡的条件。现在分开处理：穿过近裁剪面的区块自身保持可见，但其中仍合法的不透明墙面继续参与遮挡；每个实际面自身的投影和近裁剪检查不变。

使用同一已对齐真实 OptiFine ABI 的离线遍历夹具，预先静止后连续运行 20 次遍历：原地为 14 → 20 次使用优化，每次换位置为 0 → 20，同位置改变视野为 1 → 20，且不再因正常可见列表变化误报不兼容。Vanilla 与 OptiFine 模式各另有 300 帧连续位置/视野变化，与原队列算法逐项比较输出顺序、方向/计数和实体/方块实体侧列表；这些是行为与等价性证据，不是帧率测量。

下表调用完整的生产 `CurrentFrameTerrainOcclusion.filter`，每帧重新传入相机矩阵与原可见列表。场景有一组墙面及其后 512 个目标；数值是剔除数与该函数 CPU p50，不是 GPU 时间或整机 FPS。

| 场景 | 修复前剔除数 | 修复后剔除数 | CPU p50 前 → 后 |
| --- | --- | --- | --- |
| 初始静止 | 512/512 | 512/512 | 0.224 → 0.243 ms |
| 转头 20° | 0/512 | 512/512 | 0.070 → 0.154 ms |
| 前移 2 格 | 0/512 | 512/512 | 0.073 → 0.178 ms |
| 持续转头 18°–22° | 0/512 | 512/512 | 0.073 → 0.171 ms |
| 近墙持续移动 | 0–512/512 | 稳定 512/512 | 0.088 → 0.176 ms |

移动时恢复遮挡需要多做约 0.08–0.11 ms 的 CPU 工作，同时避免提交这些被遮挡目标；最终净收益取决于真实场景的绘制成本，仍需游戏内比较。新增探针位于 `tools/SoftwareTerrainMovementBenchmark.java`，只作开发验证，不进入游戏运行时。

移动修复后的最终构建通过：普通测试 1008 项，其中 986 通过、22 跳过、0 失败；最终安装包的独立加载测试另有 10 项全部通过，打包内容检查通过。已重新生成 `build/libs/ice-rlcraft-optimizer-1.0.14.jar`，未修改游戏实例。

### 既有渲染与构建验证

- 实际 OpenGL 离屏地形对照：5 组场景逐像素一致，覆盖 atlas/lightmap、alpha test、透明顺序、径向雾、平面雾、平面着色、region/动画平移及绘制状态恢复。设备为 NVIDIA GeForce RTX 4060 Laptop GPU。
- 最终编译产物的模型离屏对照：12 组场景逐像素一致，覆盖光照、法线缩放、双面材质、雾、颜色切换、嵌套矩阵失效、跨模型范围 pop 和调色板分段。常规 70 部件从 70 次绘制合为 1 次，颜色切换场景为 2 次；不支持的 texgen 场景保持原路径。
- 模型可见部件组合保留每首部件最多 4 个缓存变体，合并网格总数最多 96；8/16 部件交替测试在预先建立两种组合后没有新建 GPU 资源。
- 检测精简前的合成嵌套多轴模型 CPU 提交基准，旧状态合批 → 新路径：8 部件 14.873 → 8.113 µs，32 部件 48.461 → 36.705 µs，70 部件 134.216 → 122.155 µs，128 部件且每部件 6 面 189.813 → 177.372 µs。数据包含模型范围开始/结束与矩阵恢复，不代表整个实体渲染或整帧收益；本轮未重新测量性能。
- 检测精简前的软件遮挡 CPU 基准：512 个候选的开放视图 p50/p95 为 0.146/0.287 ms；513 个候选的遮挡视图为 0.269/0.413 ms；512 面捕获为 0.091/0.155 ms。不包含首次纹理不透明认证及图层 GL 状态查询，不能直接换算成游戏 FPS。
- 检测精简后的最终构建通过：普通测试 981 项，其中 959 通过、22 跳过、0 失败；最终 Optimizer / Profiler 安装包的独立加载测试另有 10 项全部通过，打包内容检查通过。17 组离屏画面对照保持零像素差，新增无所有权地形零 GL 调用、直接模型准入及外部模型入口回归通过。
- 快捷键更新后的构建通过：普通测试 1000 项，其中 978 通过、22 跳过、0 失败；安装包独立加载测试另有 10 项全部通过。覆盖暂停/恢复、原模块状态保留、旧 Worker 结果隔离、模型 Pending 保留与冷端捕获、缓存入口回原路及存档压缩队列退出。新增真实 OpenGL 离屏探针验证暂停时延迟纹理补传、像素正确、活动纹理单元/纹理绑定/unpack PBO 恢复，恢复后复用同一渲染资源图。
- 快捷键检测精简后的最终构建：普通测试 1001 项，其中 979 通过、22 跳过、0 失败；安装包独立加载测试另有 10 项全部通过。真实 OpenGL 探针分别验证状态镜像已知与未知两种情况下的纹理补传和绑定恢复，像素结果均正确；未新增游戏内检测或进行实际 FPS 测量。
- 以上探针均为开发工具，不在游戏运行时执行。尚未进行实际游戏 FPS 测试；模型探针未覆盖真实受伤叠加与多纹理贴图，SRP / LLibrary 整包场景仍需实机确认。
