ICE 项目目录与发布归档
更新：2026-11-07，版本 1.20.3

纳入 Git 的维护内容
------------------
src/        优化器、Profiler、启动适配器及测试源码。
tools/      构建、诊断、性能比较和崩溃收集工具。
packaging/  安装及崩溃收集说明。
docs/       发布说明、工作记录、实验结论和图像资源。
gradle/     Gradle Wrapper；根目录保留构建脚本和版本配置。

历史失败实验和性能比较结论继续保留在 docs/，不要因为临时文件被归档而
重复执行已被否定的实验。根目录的旧 F6 渲染审查记录归入 docs/。

仅保留本地、不提交到 Git 的目录
-----------------------------
releases/1.20.3/：当前可安装 JAR、安装 ZIP、源码/构建证据 ZIP 和校验文件。
releases/1.20.2/、releases/1.20.1/：历史冻结发布制品和校验文件。
build/：可再生成的构建输出；保留当前交付副本和必要的本地测试证据。
.gradle-sandbox-home/、.gradle/：当前可用的构建依赖与缓存。
.refactor-backups/：现有基准工具依赖的少量基线及测试夹具。
local-archives/20261020/：整理前历史材料的压缩归档和清理清单。

历史归档
--------
uncommitted-ice-2.0-checkout.zip 保存旧 .publish-iceoptimizer 的完整目录，
包括 .git、已修改源码和未跟踪源码；这些未完成的 2.0 工作不属于 1.20.1。
historical-builds-and-diagnostics.zip 保存旧性能记录、试验源码、构建输出、
回滚包和临时诊断。ZIP 内路径相对于项目根目录，包含文件清单。
清理前验证两份 ZIP 的完整性；cleanup-plan.json 记录哈希及待清理路径，
cleanup-result.json 记录执行结果。需要恢复时只解压所需路径到独立目录，
先比较源码；不要直接覆盖当前工作树。

两个旧的干净发布检出（1.0.6、1.0.13）在确认提交已包含于 main 历史后移除。
自动生成的 Forge 启动测试目录、过期类文件、反编译临时文本和 Python
缓存清理；保留源码、工作记录、当前发布制品和构建依赖。
原游戏实例、mods、配置和存档未参与此次清理。

发布方式
--------
仓库保存源码、文档和测试。可安装 JAR、体验包与源码/构建证据作为 GitHub
Release 附件分发；不把缓存、历史归档和本机运行数据加入 Git。
v1.20.3 沿用 1.20 系列预发布渠道，Minecraft 版本仍为 1.12.2。
