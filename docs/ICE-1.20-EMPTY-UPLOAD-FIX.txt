Code evidence and deterministic reproduction
-------------------------------------------
Reviewed Forge 2860 source and the previously captured actual transformed
OptiFine RenderChunk/RenderGlobal bytecode. RenderGlobal schedules transparency
resorts for layers that were STARTED, which can still have no emitted geometry.
RenderChunk.resortTransparency returns without beginning/finishing its builder
when the layer is empty or has no state. ChunkRenderWorker nevertheless submits
the translucent builder for upload. A pooled builder can retain the byte limit
and translation of its previous upload: reset clears vertexCount, not bytes.
ICE checked the byte limit and coordinates before accounting for empty output.
Nothirium's local reference independently separates unused/zero-vertex builders
from upload; no Nothirium code or dependency was added to the release.

Test-only reproduction against pre-fix compiled code produced:
stride=28, count=0, mode=7, position=0, limit=112, layer=Translucent.
It throws the same layout exception. The test's chunk is GL-free, so its null
position is not an observed game location. See 120-empty-upload-red-test.log.
Diagnostic JAR differs from released 1.20 only by more detailed exception text:
2E07FCCC77A3838C524329363D8AFFA5B5A8B9607FCF70CDECE230E106327465.
Two fresh natural-game diagnostic runs did NOT reproduce the full user crash:
live-120-upload-layout-diagnostic (rotating views + real F6 OFF/ON), and
live-120-upload-layout-movement (static/rotation/local movement with JFR).
Thus the fixed boundary is proven, but do not claim the user's exact sequence
was reproduced or that every possible layout exception has been eliminated.

Change
------
An empty compiled layer or zero vertex count is an empty publication. Retire
any prior native mesh, clear its VBO count, reset the builder, and return before
creating GL storage or inspecting stale vertex bytes/coordinates. Release also
invalidates the draw queue and detaches the final resident section. Nonempty
geometry keeps the existing layout/coordinate contract and full visual data.
The exception now includes stride/count/mode/bounds/layer/chunk if a genuinely
nonempty incompatible payload reaches it. This adds no per-frame diagnostic
logging, fallback renderer, performance gate, or suppressed error.
